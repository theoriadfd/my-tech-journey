# Python

Упражнения по Python.

## Как запустить скрипт

1. Установите Python с [python.org](https://www.python.org/downloads/).
2. Откройте терминал в папке со скриптом.
3. Выполните команду:

```bash
python 01_hello.py
```

На macOS и Linux иногда нужно писать `python3` вместо `python`.
